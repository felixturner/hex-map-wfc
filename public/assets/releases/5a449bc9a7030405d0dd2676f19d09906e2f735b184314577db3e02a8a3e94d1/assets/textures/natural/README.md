# Natural terrain textures

Generated with the built-in ImageGen tool for this project. These are color
textures, sampled in world space by `src/hexmap/NaturalMaterial.js`. Existing
KayKit atlas UVs still identify grass, stone, roads, foliage, and water.

## meadow.png prompt

Use case: photorealistic-natural. Asset type: seamless repeating base-color texture for a real-time 3D game terrain material, square 1024x1024. Primary request: overhead orthographic scan of alpine meadow ground, short fine olive and sage green grasses, tiny dried straw blades, patches of earthy brown soil, scattered tiny grey pebbles and moss. Represents a 3 metre square of terrain viewed straight down. Dense intricate natural surface detail, restrained muted greens, no large objects. Perfectly flat evenly overcast diffuse lighting, no directional shadows, no ambient occlusion baked into image, no perspective, no horizon, no vignette, no text, no borders. Seamless tileable edges. This is an albedo texture filling the whole image, not a landscape or a rendered material sphere.

## rock.png prompt

Use case: photorealistic-natural. Asset type: seamless repeating rock albedo texture for a real-time 3D alpine terrain material, square 1024x1024. Primary request: detailed weathered grey limestone and dark slate rock face, fine angular fractures, narrow fissures, subtle layered stone strata, tiny granular mineral detail. Represents a 3 metre square rocky surface viewed straight on. Neutral cool-grey with subtle warm grey areas. Perfectly flat diffuse ambient lighting, no directional shadows, no deep dark holes or dramatic relief shadows, no snow, no moss, no objects, no perspective, no horizon, no vignette, no text, no border. Seamless tileable edges. This is a natural photographic base-color texture filling the entire image, not a landscape, not a material sphere, not a mountain.
